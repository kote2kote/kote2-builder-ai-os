# OS機能一覧

ここは利用者向けの機能と頼み方の入口です。呼びかけをAIに渡すと、必要な手順や確認へ進みます。Wiki上の操作で制作・導入・更新・公開を自動実行しません。コマンドは端末で実行するものとAIへの入力を区別してください。

## 記録・知識・日々の仕事

| 機能 | 呼びかけ言葉 | 詳しい手順 |
|---|---|---|
| 相談・仕事の再開 | 昨日の続きから進めたい | [普段の入口](../AGENTS.md) |
| Wikiの閲覧・検索・カテゴリ・つながりのグラフ | Wikiを見せて。この内容に関係する知識を探して | [Wikiの使い方](../wiki/README.md) |
| 毎日メモ（日付ごとの索引） | 今日のメモを見せて | [毎日メモと記録](../wiki/README.md) |
| Wikiの編集・保存・履歴・復旧 | この記録を直して。前の状態に戻せるか確認したい | [保存と復旧](save-status.md) |
| 未確認の提案・過去の判断と後日の結果の整理 | この案は未確認として残して。試した結果を判断に追記して | [記録の区別](../wiki/README.md) |
| Wikiの入口・リンク不足の点検 | Wikiの入口が抜けていないか点検して | [入口の点検](../wiki/README.md) |
| 自分のことを伝える・初回ヒアリング（任意） | 私のことを最初から知るための初回ヒアリングを始めて | [初回案内](onboarding.md) |
| テーマについて考えを整理する・ヒアリングモード | このテーマでヒアリングモードを始めて | [ヒアリングモード](interview.md) |
| v3からの知識の移行・分類 | v3の知識を移したい。まず内容を確認して | [移行の手順](v3-migration.md) |

正式名は「ヒアリングモード」。「インタビューして」「インタビューモードで」でも同じモードを呼び出せる。話題がなければ1問で確認し、初回7項目やプロフィール登録を必須にしない。

Wikiの起動コマンド（端末）: `python3 tools/wiki_view.py open view`。呼びかけ: 「Wikiを開いて」。グラフは `python3 tools/wiki_view.py open graph` / 「知識のつながりをグラフで見せて」。保存や復旧では差分・対象を確認し、秘密や本人の未保存編集を守ります。

## 案件を作る・続ける

| 機能 | 呼びかけ言葉 | 詳しい手順 |
|---|---|---|
| 新しい制作・設計・完成条件の確認 | こういうものを作りたい。まず設計から相談して | [制作の流れ](building/index.md)・[設計](building/design.md) |
| 案件のWiki・README・ダッシュボード | この案件のダッシュボードを見せて | [案件の最小構成](building/project.md) |
| 案件の成果物の置き場 | この案件の成果物の置き場を確認したい | [案件の配置](building/project.md) |
| v3のoutputを案件ごと・一括でコピーする | outputの成果物をまとめて移したい。原本を残し、コピー前に計画を見せて | [成果物コピーの手順](v3-migration.md) |
| 案件完了と記録の整合 | この案件を完了にしたい。成果物と記録の状態を確認して | [案件の記録](../wiki/README.md) |
| 案件から残した、親Wikiへ未反映のメモの取り込み | 案件で残した未反映のメモを取り込んで | [未反映メモ](../wiki/README.md) |
| 外部で作った既存案件の接続 | この既存案件をここで管理して続けたい。原本を変える前に計画を出して | [既存案件の接続](building/existing-projects.md) |
| ZIPからの試作引継ぎ | この試作ZIPを参考に、アプリにできるか確認して | [試作の引継ぎ](prototypes.md) |
| 設計後の触れる試作 | まず触って試せる試作を作って | [スキル一覧](#/skills) |
| 図解・見た目のレビュー・説明動画 | 仕組みを図解して／デザインをレビューして／説明動画にして | [スキル一覧と呼出コマンド](#/skills)（説明動画はClaude Code専用） |
| 見た目の標準・自分用のデザイン設定 | この資料の見た目に合わせたい。設定案を見せて | [見た目の設定](design.md)・[標準](../DESIGN.md) |
| 検証・完成判定 | この案件を検証して。未確認も教えて | [検証](building/verification.md) |
| 古い方法・環境差・外部仕様の見直し | この作り方は今も使えるか、公式情報で確かめて | [方法の見直し](building/freshness.md) |

静的検査コマンド（端末）: `python3 tools/building_check.py --project projects/<名前>`。呼びかけ: 「この案件の構成と設定を検査して」。静的検査は実際のAI読込や実動作の保証とは別です。

| 機能 | 呼びかけ言葉 | 詳しい手順 |
|---|---|---|
| レシピを探す・使う・残す | レシピを見せて。このやり方をレシピにしたい | [レシピ](recipes.md) |
| レシピを再現する・持ち出すZIP | このレシピを再現したい。ZIPにまとめたい | [再現とZIP](recipe-reproduce.md) |

スキルのコマンドと呼びかけ言葉のセットは [スキル一覧](#/skills) にあります。追加・削除後は一覧の「再読込」で更新できます。

## OSの設定・導入・更新

| 機能 | 呼びかけ言葉 | 詳しい手順 |
|---|---|---|
| 初期導入・必要な道具の確認 | このOSを始めたい。必要なものを確認して | [導入](setup.md) |
| Claude/Codexの設定・安全性の確認 | このAIの設定を確認して。変更前に差分を見せて | [AI設定](building/settings.md)・[安全確認](safety.md) |
| AIとの進め方の好みを設定 | 毎回の進め方を、私に合わせて相談したい | [進め方の設定](ai-preferences.md) |
| OSの更新 | OSを更新して。変更点と守られるデータを先に見せて | [OS更新](os-update.md) |

機能ごとに一律の端末コマンドがあるわけではありません。表示のコマンドは対象・条件を確認してから使います。OS更新・スキル導入・公開はそれぞれ必要な本人確認を省略しません。将来構想や未導入のプラグインを実装済み機能に含めません。
