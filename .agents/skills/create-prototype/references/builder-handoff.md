## OS が無い時は
- Claude Code などの AI にこのフォルダを渡して頼めます。何をしたいかをはっきり伝えてください。「続きを作って」だけだと、試作をもう一段よくした次の試作（架空のデータのまま）になることがあります

- 試作の中のプログラム（app.js など）は画面の動きのためのものです。配った人を信頼できない時は開かないでください
