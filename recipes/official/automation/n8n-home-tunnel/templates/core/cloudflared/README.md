# cloudflared/ — このマシン専用のトンネル設定

| ファイル | 役割 | Git |
|---|---|---|
| `config.example.yml` | トンネル設定のひな型 | 管理する |
| `admin.yml` | トンネル管理コマンド(作成・削除など)に、既存の `~/.cloudflared/config.yml` を読ませないためのダミー | 管理する |
| `config.yml` | `scripts/setup.sh` が書き出す本物(トンネル ID と認証ファイルの場所入り) | 管理しない |
| `run/` | 起動中トンネルの PID とログ | 管理しない |

トンネルの認証ファイル(`{トンネルID}.json`)は `~/.cloudflared/` にあり、このフォルダには置きません。

**なぜ `--config` を毎回明示するのか**: `~/.cloudflared/config.yml` に別のトンネル(以前の設定や、他のマシンと同じトンネル)の設定が残っていることがあります。明示しないと cloudflared がそちらを読み、別のトンネルを動かしたり、全部 404 になったりします。
