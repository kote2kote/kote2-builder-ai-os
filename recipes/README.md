# レシピの置き場

「レシピ一覧見せて」と頼むと、製品名・概要・確認状態を旧ビルダーと同じ表で見られます。「N番で作って」「製品名で作って」で選び、設計を見てOKしてから作ります。一覧を見ただけでは導入やファイル変更はしません。

## スターターに付属する10件

旧ビルダーのフリー配布物から、次のレシピを旧形式のまま引き継いでいます。本文・テンプレート・試験・画像はパッケージ単位で扱います。`notion-wp`も有料版専用記述を除いたフリー配布版です。

- 自宅n8n公開キット（n8n-home-tunnel）
- マルチチャネルAIチャットボット（omni-chatbot）
- 説明映像（explainer-video）
- フォルダ隔離サンドボックス（claude-docker-sandbox）
- サンドボックス体感道場（sandbox-handson）
- AI検索ナレッジ（ai-search-knowledge）
- ファイル便（file-bin）
- 社内HTML共有ボード（html-share-board）
- 漫画コマ検索（manga-koma-search）
- Notion風WordPress（notion-wp）

## 確認状態と使う前の注意

旧依存・欠けた参照先・個別の安全指示は [旧無料レシピの補足](../tools/building/legacy-recipes.md)へ。素材の旧全体利用条件の参照先は未確定のため、素材を含む公開配布版の出荷は保留中です。自分の環境での利用確認と、他の人への再配布を分けて扱います。

- 旧形式の`verified`・Mac/Win・配布元検証は旧ビルダーでの記録です。このOSで全10件を作り直したことや、現在の外部サービス・料金・モデルへの対応を保証しません。使う前にレシピ本文を読み、必要な現在の仕様を確かめます。
- 説明映像はワークスペースへ機能を足すレシピで、通常の案件とは別です。旧版の記録ではClaude Code専用。追加するファイルと対応AIを見せ、了承後に進めます。Codexで制作できると扱いません。
- 旧`llm-wiki`は今のOSのWikiと役目が重なるため、スターターには入れていません。移行した人の手元にあるものを削除・非表示にはしません。
- 旧版の`output/`・専用検証道具・知識への参照は、[旧形式の読み替え](../tools/recipes.md#v3-のレシピ)に従います。付属していない旧資料を読んだふりはせず、不足と補う方法を伝えます。旧ビルダー本体や元の完成品は必要ありません。
- 外部公開・課金・アカウント設定・個人データの扱いは、本人に確認してから行います。

## 自分のレシピを足す

配布された単体Markdownやパッケージをこの下へ置けます。パッケージは`recipe.json`・`RECIPE.md`・`templates/`・`tests/`などを崩さずフォルダごと置きます。OSで新しく作る形は[レシピの手順](../tools/recipes.md)を参照してください。

`official/`はスターター由来の置き場です。自分のものは`my/`など別のフォルダにも置けます。名前（ID）は全体で重複させません。一覧は追加したレシピも再帰で見つけます。本人のレシピを通常のOS更新で追加・置換・公開することはありません。
