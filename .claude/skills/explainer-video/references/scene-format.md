# 場面データ(scene.js)の書き方

`scene.js` は `window.VIDEO = { ... }` を 1 つ書くだけのファイル。エンジン(`engine/explainer.js`)がこれを読んで、`render(t)` で「t 秒目の 1 コマ」を決定論で描く。完全な例は `examples/mcp/scene.js`。

## 全体

| キー | 中身 |
|---|---|
| `fps` | 書き出しのコマ数(既定 30) |
| `map` | 地図の大きさ `{ w, h }`(既定 1920 × 920。画面の下 160px は字幕の帯) |
| `theme` | 色の上書き。`{ frame: '#3a5a8c', accent: '#c0392b' }` のように CSS 変数名(`--` を除く)で書く。変数は `engine/explainer.css` の先頭 |
| `title` | タイトル場面 `{ eyebrow, title, sub, dur, pose }`。`sub` は `<br>` 可。無ければタイトル無しで始まる |
| `art` | この映像だけの絵 `{ 名前: 'SVG' }`(下の「絵」)。同梱の絵と同じ名前なら、こちらが勝つ |
| `items` | 地図の上の箱(下) |
| `arrows` | 矢印(下) |
| `tags` | 吹き出しの札 `{ id, text, x, y, c, icon }`(`x, y` は中心。`c` は `o` / `g`。`icon` は文の頭に付く絵) |
| `legend` | 凡例 `{ pos: { left, top }, items: [[色, 文言, 破線なら true]] }`。`pos` は画面上の px(地図ではない) |
| `scenes` | 場面の配列(下) |

## items(箱)

`{ id, x, y, w, h, cls, html, visible, icon, iconAt, iconSize }`

- `cls`: `box`(既定)/ `box soft`(脇役)/ `box dash`(外のもの・まだ無いもの)/ `box strong`(主役)/ `box top`(中身を上詰め)/ `chip`(小さな札)/ `zone`(区画の見出し。枠なし)/ `art`(絵だけ。下の「絵」)
- `html` の中で使える型: `<div class="eb">英字の小見出し</div>` / `<div class="k">大きな名前</div>` / `<div class="d">説明</div>` / `<span class="mono">ファイル名</span>` / `<div class="row" id="...">1 行ずつ出す行</div>`
- 箱の文字は折り返さない。長いと箱からはみ出すので、`w` を広げるか言葉を短くする
- `visible: true` は最初から出しておく(既定は、場面の `show` で出るまで見えない)
- `icon`: 箱に添える絵の名前(下の「絵」)

## arrows(矢印)

`{ id, d, c, dash, head, label, labelAt, packet, packetIcon, packetPath, visible }`

- `d`: SVG のパス(例 `'M272,210 C350,210 350,175 426,175'`)。箱の端から端へ。矢じりは終点側
- `c`: `g` 主な流れ(既定)/ `o` 返事・注意 / `s` 参照・比較(細い)
- `dash: true` 破線 / `head: false` 矢じり無し(区切り線など)
- `label` + `labelAt: [x, y]`: 線の横に置く文言
- `packet`: 線の上を動くラベルの既定文言(場面の `packet` で上書き可)
- `packetIcon`: 動くラベルの頭に付ける絵の名前。`packet` を空にすると、絵だけが丸い札で動く(封筒が届く、など)
- `packetPath`: 短い矢印でラベルが箱に隠れる時、ラベルだけ別の長い経路を通す

## scenes(場面)

`{ dur, pose, step, caption, cam, camMove, side, at }`

- `dur`: 秒。**音を足す時はナレーションの長さをここに入れる**(後ろは自動でずれる)
- `pose`: キャラのポーズ名(`character/character.js` の `poses` のキー)。無い名前はエラーで止まる
- `step`: 字幕の左の札(「1 これまで」「まとめ」など。無くてもよい)
- `caption`: 字幕。1 文・40 字前後まで
- `cam: [注視 x, 注視 y, 倍率]`: 地図のどこを画面の中心に置くか。前の場面のカメラから `camMove` 秒(既定 1)で移る。全体を見せる時は `[960, 432, 0.97]` 前後
- `side: 'R'`: キャラを右、字幕を左に(図の左下を見せたい時)
- `at`: その場面で起きること `[[場面の頭からの秒, 種類, id, (packet の文言)]]`
  - `show` 箱(`items` の id)や、箱の中の `.row` を出す(箱は「ぽんと出る」、`.row` は「横から滑り込む」。札は `tag` で出す)
  - `draw` 矢印を描く(0.6 秒)
  - `packet` 矢印の上をラベルが動く(1.2 秒)。先に `draw` しておく。`[秒, 'packet', id, 文言, 絵の名前]` で、その回だけ文言と絵を替えられる
  - `tag` 札を出す
  - `legend` 凡例を出す(id 不要)
  - `pulse` 箱・行・札を 0.6 秒だけ少し大きくして目を引く(字幕がその部品の話をする時に。同じ部品に何度でも)

## 絵(アイコン・イラスト)

文字だけの図にしない。箱には絵を 1 つ添え、話題に固有の物は描き足す。

| 置き方 | 書き方 | 見え方 |
|---|---|---|
| 箱に添える | `{ id, ..., icon: 'mail' }` | 箱の左に、淡い台紙つきで。大きさは箱の高さから決まる(`iconSize: 64` で指定)。狭い箱は `iconAt: 'top'` で文字の上に |
| 小さな札に添える | `{ cls: 'chip', icon: 'plug', html: 'クライアント' }` | 文字の左に台紙なしで |
| 絵だけを置く | `{ id, cls: 'art', icon: 'box', x, y, w, h, html: '見出し' }` | 枠なしで w × h いっぱいに。`html` は絵の下の見出し。`show` で「ぽんと出る」 |
| 文の中に | `html: '<i data-icon="tool"></i><b>道具</b>'` | 文字と同じ高さで |
| 動くラベル・札 | 矢印の `packetIcon: 'doc'` / 札の `icon: 'shield'` | 文言の頭に白い丸で |

- **同梱の絵**: `engine/icons.js` の 50 個(人・機械・書類・連絡・時間・安全・道具)。名前と意味はそのファイルの各行、見た目は `references/icon-catalog/index.html` を `--stills 1` で撮った画像で確かめる
- **描き足す絵**: `art: { usbc: '<svg viewBox="0 0 170 100">…</svg>' }` のように、その映像の `scene.js` に書く(例: `examples/mcp/scene.js` の USB-C)。`<svg` で始めない時は中身だけとみなし、`viewBox="0 0 64 64"` で包む
- **絵柄の約束**(同梱と並べて浮かないように): 塗りは色のクラス `f-frame` 緑 / `f-leaf` 薄緑 / `f-accent` 錆色 / `f-wood` 段ボール色 / `f-sun` 黄 / `f-sky` 灰青 / `f-paper` クリーム / `f-card` 白 / `f-ink` 濃い色。輪郭は `ol`(塗りと一緒に)、線だけは `ln`(`ln w` 白 / `ln g` 緑 / `ln o` 錆色 / `ln d` 段ボール色 / `ln s` 黄。太さは `style="stroke-width:5"`)。部品は 3〜12 個の平らな形。色を `fill="#..."` で直接書かない(`theme` に追従しなくなる)。グラデーション・影・光の粒・絵の中の文字・会社や製品のロゴは描かない
- 色は `explainer.css` 先頭の変数(`--leaf` `--wood` `--sky` `--paper` `--line` ほか)。`theme` で上書きすると、同梱の絵も描き足した絵も一緒に変わる
- 書き間違えた名前はエラーで止まる。1.1.0 より前に作った映像に絵を足す時は、その `index.html` の `scene.js` の行の前に `engine/icons.js` を読む行を足す(無いとエラー文で知らせる)

## 決まりごと

- 一度出したものは消えない(積み上がって、最後に全体を見せる構成が基本)
- 地図の外(マイナス座標・1920 超え)にも置けるが、全体に引いた場面で入るように置く
- 書き間違い(無い id・ポーズ・絵の名前・場面の長さを超える時刻)はページのエラーになり、書き出しが止まる
- 箱の中身のはみ出しは「注意」として出る(書き出しは止まらない。フォントの違いで端末ごとに数 px 変わるため)。出たら `w` / `h` を広げるか言葉を短くする
